快捷方式

放到桌面或开始菜单，方便下次打开。安装包里也可以勾选「创建桌面快捷方式」。

—

模型选择器解锁（启动器自有）

解除「只能选 Auto」：FREE 锁 + 命名视图门闩 + 目录补 namedModelSectionIndex。你已有 YC 模型墙时，只需点「仅解锁 MAX」（只改 hideMaxToggle，最不易黑屏）。完整解锁含会员 fetch 伪装。须先关 IDE，启用后用启动器重启并新开一轮对话。

—

模型回包改写（启动器自有）

不依赖混淆网关。给 Cursor 的扩展宿主挂钩，改写 AvailableModels / GetServerConfig / Agent 响应里的窗口字段（Grok Extra High 256k→500k）。需本机 Node.js；须先关 IDE。升级 Cursor 后补丁会丢，需重打。可随时还原。

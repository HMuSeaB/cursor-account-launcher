# 视觉升级验证报告：独立莫兰迪暮粉（图一）与极客深紫拆分

## 1. 改造背景与需求
- **用户反馈**：“你这个颜色新建一个啊，这个紫色和粉色明显不是一个调色盘啊”。
- **问题根源**：此前将图一的“温润藕粉/暮紫质感”直接覆盖到了原有的 `violet`（紫色）配色上，导致在日间模式下是亮紫色、暗黑模式下是烟熏粉色，且用户原本喜爱的极客正统紫色配色被混淆。
- **解决方案**：
  1. 将图一中广受好评的质感独立新建为专属的 **“温润暮粉 (`mauve`)”** 独立调色盘；
  2. 将 **“星云幻紫 (`violet`)”** 还原为纯正、深邃的高级极客紫调色盘（日间亮紫、夜间暗夜霓虹紫）；
  3. 调色盘面板（Material You Popover）扩展至 6 大调色芯片，支持自由秒切。

---

## 2. 调色盘体系划分

| 色彩方案 | 内部标识 | 核心视觉风格 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **温润暮粉** | `mauve` | **对标图一**：深邃烟熏粉夜景（`#181518`/`#252025`），温润灰粉胶囊按钮（`#ded1d5`），日间为高级莫兰迪藕粉 | 柔和微暖、耐看不刺眼 |
| **星云幻紫** | `violet` | **正统紫色**：深空星海背景（`#0e0d17`/`#1c1930`），纯正紫罗兰高亮（`#7c3aed`/`#a78bfa`） | 赛博极客、科技深邃 |
| **黑曜极客** | `obsidian` | 黑曜石黑灰与高对比纯白 | 极简专注 |
| **深海曜蓝** | `cobalt` | 经典科技商务蓝 | 专业严谨 |
| **极客暖金** | `amber` | 暖阳琥珀金橙 | 温暖活力 |
| **墨翠翡绿** | `emerald` | 青翠墨玉翡翠绿 | 清新护眼 |
